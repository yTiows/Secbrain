# Orion project overview

Orion is our research project to build a recommendation and retrieval engine for the marketplace catalogue. The goal for the first milestone is a hybrid retrieval prototype with measurable precision. The deadline for the prototype is September 30.

## Stack
The prototype is written in Python and uses PyTorch for model experiments. Evaluation scripts run in notebooks and CI.
