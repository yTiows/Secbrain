# New engineer onboarding

## Laptop setup
1. Install Docker Desktop and the company VPN client.
2. Clone the Atlas monorepo and run the bootstrap script.
3. Start the local stack with docker compose and open the developer portal.

## First week
Pair with an on-call engineer for one shift. Read the architecture overview and the API conventions before your first pull request. Ask questions in the platform channel.
